# Система прогнозирования остаточного ресурса оборудования (RUL)

Программная система прогнозирования остаточного ресурса (Remaining Useful Life, RUL) турбовентиляторного двигателя на основе многомерных временных рядов датчиков.

## О проекте
Выпускная квалификационная работа (ВКР) бакалавра.
**Учебное заведение:** Московский авиационный институт (МАИ), ФИИТ.
**Автор:** Еряшев Алексей Дмитриевич, группа 412.
**Научный руководитель:** Стрижак Сергей Владимирович.

## Цель работы
Разработка сквозной программной системы для перехода к обслуживанию оборудования по фактическому состоянию. Система должна прогнозировать остаточный ресурс и давать рекомендации по планированию ремонта.

## Данные
В работе используется открытый датасет **NASA C-MAPSS** (FD001–FD004) — смоделированные траектории работы турбовентиляторных двигателей до отказа.

## Планируемый стек технологий
*   **Язык и библиотеки:** Python 3.11, pandas, NumPy, scikit-learn, LightGBM, PyTorch
*   **Foundation-модели:** Chronos (Amazon), TimesFM (Google)
*   **Сервис и интерфейс:** FastAPI, PostgreSQL / TimescaleDB, Streamlit
*   **Инфраструктура:** MLflow, pytest, Locust
